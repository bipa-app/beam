# Beam AI brand

## Name

- Product: **Beam AI**.
- CLI command: **`beam`**.
- Domain: **beamai.sh**.
- Tagline: **Your coding agent keeps moving.**

Use “Beam” in prose after the first “Beam AI”. Keep `beam` lowercase only when
it names the command or a literal path.

## Identity

The Afterimage mark freezes one photon in motion. A solid line shows the live
handoff. Two fading lines show where the work was a moment ago. The lowercase
`b` anchors the system without turning the mark into an arrow, cloud, portal,
or link icon.

The logo is static. Motion belongs to product transitions, not to the mark.

## Color

| Token | Hex | Use |
|---|---|---|
| Ink | `#090B10` | Type, dark surfaces, the primary mark |
| Paper | `#F7F5EE` | Primary light background |
| Photon | `#FFD84D` | Movement, active transit, and successful arrival |
| White | `#FFFFFF` | Type and the mark on Ink |
| Muted | `#62636A` | Supporting copy |
| Line | `#CBC8BD` | Rules and quiet borders |

Photon yellow has one job: show movement. Do not use it as general decoration,
for warnings, or to fill large interface areas except a focused call to action.

clear space around either asset equal to the width of the `b` stem. Never crop
the afterimage lines.

## CLI

The command stays plain. The identity appears through concise language and one
terminal accent:

- `landed` after a successful handoff;
- `returned` after a verified collection;
- one photon line while the workspace is moving.

Color is optional. Photon yellow appears only on a TTY, respects `NO_COLOR`,
and never enters JSON output.

## Do not

- Add arrows, clouds, lightning bolts, chain links, portals, or gradients.
- Animate the logo continuously.
- Change the proportions or spacing between `beam` and `ai`.
- Recolor the photon line.
- Put the dark asset on a light surface or the light asset on a dark surface.
- Use title case for the command.
